What is a network command?

A command is an instruction used to request network information or test a specific behaviour. The simulator accepts a small, safe set of familiar command patterns and models their results in Python.

Command reference

Select “Run in console” to load an example into the live console.

Classroom tip

Compare TCP and UDP: TCP establishes a connection and provides reliable, ordered delivery; UDP sends datagrams without a connection handshake and does not guarantee delivery.

LAN in a nutshell

A Local Area Network connects devices in a limited area. Devices in the same IPv4 subnet can typically communicate directly at the data-link layer after address resolution, without sending the traffic through a router.

MODULE 05 · PATH SELECTION

Routing & packet paths

Routers forward packets between IP networks using destination addresses and routing tables.

05
⇄
How a router decides

The router checks the destination IP against its routing table and forwards a packet using the best matching route. A host typically sends traffic for remote networks to its default gateway.

Key distinction

A switch forwards frames within a LAN using MAC addresses; a router forwards packets between IP networks using IP addresses and routes.
